# Server

Erweiterungen für den eigenen beelogger-Webserver (PHP), geplant:

- Webhook-Eingang mit Verteilung nach Gerätename (`{/devID}`) auf die Logger-Verzeichnisse
- Werte der Wetterstation SenseCAP S2120 als Standreferenz speichern
- Übertragung an BEEP mit Messzeitpunkt

Zugangsdaten gehören in nicht versionierte Dateien (siehe `.gitignore`).
